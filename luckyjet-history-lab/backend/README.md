# Облачная проверка Lucky Lab

`schema.sql` создаёт отдельные `lucky_lab_state` и `lucky_lab_windows`. Существующий сборщик игры не изменяется. Таблицы закрыты RLS: браузер вызывает только `lucky_lab_report`, серверные claim/finish/verify недоступны anon.

Supabase Edge Function `lucky-lab-worker` запускается заданием `lucky-lab-cloud` каждые 30 секунд. Вызов защищён серверным заголовком из Supabase Vault. Используются уже настроенные серверные переменные `SUPABASE_URL`, `LUCKYJET_MIRROR_KEY` и `LUCKYJET_COLLECTOR_TOKEN`; их значений в исходном коде нет. Функция не вызывает Gemini и не отправляет уведомления.

Один запуск получает атомарную аренду на 90 секунд. Пока закреплённый прогноз действует, новая большая выборка для него не загружается. История крупных целей перечитывается при новом событии ≥10×. Окна создаются только на свежем источнике после разогрева; повторный ID не изменяет исходные параметры.

Формулы из опубликованной версии сохранены; часовые признаки теперь явно используют Europe/Kyiv, включая переход летнего времени. В браузере используется результат серверного расчёта, а не второй независимый генератор.

Попадание подтверждается точным завершённым раундом после регистрации и внутри окна. Результат содержит коэффициент, ID и UTC-время. Источник не подтверждает полный игровой порядок, поэтому отсутствие цели после окончания окна остаётся unknown. Неизвестные окна перепроверяются раз в 5 минут. Завершённые результаты не перезаписываются. Окна могут перекрываться и не являются независимыми испытаниями; точность не подтверждена.

Облачный журнал не удаляется по закрытию страницы. Сайт показывает последние 200 облачных записей, а сервер сохраняет все записи. Старый локальный журнал остаётся в своём браузере с отметкой «Локально»; переноса личных данных в публичную базу нет.

Проверки: unit-тесты `tests/cloud-plan.test.mjs`; `regression.sql` исполняется целиком с ROLLBACK, без сохранения тестовых записей. Проверяются исходные времена, доказательство попадания, неполная история, аренда и права anon. Проверка в браузере закрывает все тестовые страницы и процесс, затем подтверждает увеличение серверного счётчика и сохранение журнала в новом браузере.

Остановка: администратор может выключить Cron `lucky-lab-cloud` и установить `enabled=false` в единственной строке `lucky_lab_state`. Сборщик раундов продолжит работать отдельно.
