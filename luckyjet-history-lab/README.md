# Lucky Lab — отдельная версия

Запуск: https://miuiproking.github.io/MiuiProKing/luckyjet-history-lab/

Статический сайт: реальные завершённые раунды из Supabase, архив с фильтрами и CSV, карточки целей 10–1000×, предыдущая сохранённая запись перед крупным результатом, экспериментальные расчёты и журнал окон.

Не требует ПК. Gemini и серверные ключи не используются; config.js содержит только публичный ключ чтения. Страница не пишет в базу и не запускает сборщик.

После перерыва unknown сверяется с архивом. Подтверждённое попадание содержит коэффициент, время и ID раунда в первоначальном окне. При неподтверждённой полноте данных отсутствие попадания остаётся unknown. Журнал хранится в браузере отдельно для каждого адреса сайта.

Формулы calculations.js опубликованы в браузерном модуле https://historique-luckyjet.shop/assets/PredictionPanel-DmmGZgIn.js и получены 11 октября 2026. engine.js проверяет входы и свежесть. large-history.js считает медиану интервала и MAD. Баллы и исторические частоты не доказывают точность прогноза или преимущество.

Локально: запустить HTTP-сервер из этой папки, например python -m http.server 8813. Основные версии приложения и главное меню сохранены.
