# Lucky Lab

Отдельная личная панель Lucky Jet. Статический сайт в `dist/`, источник — наш публичный Supabase REST с доступом только к коэффициентам. Серверные и Gemini-ключи не используются.

Разделы: обзор, Lucky Jet, дневной архив с фильтром и CSV, описание формул и локальный журнал будущих временных окон, описание данных и JSON-экспорт.

`dist/calculations.js` содержит опубликованные браузерные формулы из `https://historique-luckyjet.shop/assets/PredictionPanel-DmmGZgIn.js`, полученные 11 октября 2026. В `De` добавлен необязательный параметр текущего времени для использования часов Supabase. Арифметика и приоритеты исходных правил сохранены. `engine.js` добавляет валидацию входов и свежести; баллы не называются вероятностью.

Часовые признаки формулы используют Europe/Kyiv, отображение окон — Europe/Kyiv. В базе не подтверждена полнота игрового порядка. Журнал не является доказательством точности; окна могут перекрываться. Прерванное наблюдение отмечается unknown. Исторические коэффициенты не засчитываются как будущие результаты.

Проверки: `node --test tests/engine.test.mjs`. Локальный запуск: Python HTTP server из `dist/`. Для Sites используется `.openai/hosting.json`; публикация через штатный source helper. Сайт не изменяет исходные версии и не запускает сборщик.

Крупные цели 10–1000×: отдельный экспериментальный расчёт медианы интервала и MAD по максимум 1000 событиям ≥10×; минимум 8 точных событий. Просроченное окно не переносится. Достоверность прогноза не подтверждена. Архив фильтруется в Supabase, верхнего ограничения нет; карточки показывают предыдущую сохранённую запись, полнота порядка игры не подтверждена. Пагинация по feed_order.

Журнал: после перерыва неизвестные окна автоматически сверяются с архивом (кнопка ручной сверки также доступна). Время регистрации, цель и границы не пересоздаются. Попадание подтверждается конкретным раундом с точным временем в исходном окне; отсутствие попадания при непроверенной полноте игрового порядка остаётся unknown. Вкладки объединяют журнал по ID и не стирают завершённые результаты.

Облачная версия: расчёт и проверка работают в Supabase каждые 30 секунд независимо от браузера. Общий журнал и статус читаются через lucky_lab_report. Сервер хранит все окна; страница показывает последние 200. Сборщик раундов и старые версии не меняются. Подробности и схема: backend/README.md.
