# LuckyJet Full Logic · V1.3

Самостоятельный HTML с оригинальными формулами De / Ce и историей LuckyJet.

## Запуск

1. Скачайте `index.html` и откройте в Safari, Chrome или Edge. Страница файла на GitHub показывает исходник, а не запускает приложение.
2. В настройках выберите Crash Gateway, введите свои `Customer ID` и `Session ID`, затем нажмите «Сохранить и подключить».
3. Последний коэффициент и 20 последних раундов видны вверху сразу после ответа API. Новые запросы идут каждые 2,5 секунды.

В публичном репозитории нет персональных данных сессии. По умолчанию введённые данные хранятся только в памяти страницы. Опция запоминания сохраняет их локально в вашем браузере. Не добавляйте их в коммиты.

## Исправления V1.3

- Лента коэффициентов на первом экране, включая телефон шириной 390 px.
- Отдельный статус API, понятное сообщение ошибки и кнопка «Переподключить».
- Запуск в `srcdoc` и при недоступной History API.
- Совместимость со средами без `Array.prototype.at` и со старым названием часового пояса Киева.
- Настоящий коэффициент 1.00× сохранён; равные значения разных раундов не склеиваются.

## Данные и формулы

Gateway: `https://crash-gateway-grm-cr.100hp.app/history`, заголовки `customer-id`, `session-id`, `accept: application/json`.

API часто не передаёт время старых раундов. Такие коэффициенты отображаются сразу, а время остаётся неизвестным. Для новых раундов фиксируется интервал появления в браузере. Для расчёта De / Ce нужны минимум 20 раундов со временем. Это ограничение расчёта, а не ленты коэффициентов.

Формулы независимо реализованы по открытому клиентскому модулю:
https://historique-luckyjet.shop/assets/PredictionPanel-CBGsolff.js

SHA-256 проверенного модуля: `a7a322910c8658e41bfa82e932174eeff4419598c4d53b760c0df744b04ac08e`.
Обычный расчёт: циклы 10×, серия ниже 2×, кластеры 20×, зона 5–9×, взвешенное EMA.
Крупные события: медианный цикл 100×, кластеры 20×/50×, пуассоновская оценка интервала.
Баллы правил не являются измеренной вероятностью выигрыша; случайного генератора сигналов нет.

## Сборка и проверки

Зависимости не требуются: Python 3 и Node.js.

```sh
python3 build.py
node --check src/app.js
node test.cjs
```

`src/` содержит редактируемые исходники; `index.html` — собранная версия без внешних скриптов.
Проверяются ветви формул, идентификаторы, разбор Gateway/JSON/CSV, временные окна и отсутствие встроенной сессии.
При подготовке формулы De/Ce также совпали с исходным публичным модулем на 109 наборах данных.
