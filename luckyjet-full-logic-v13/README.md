# LuckyJet Full Logic v1.3 — Supabase

Откройте `index.html` как обычную страницу. Учётная запись ChatGPT, ввод игровой сессии и ключей не нужны. Готовая страница использует публичный сервер чтения истории; ключи Supabase в HTML отсутствуют.

Публичная версия: https://luckyjet-full-logic-v13-mpk.miuipro1993.chatgpt.site

При запуске загружается до 2000 реальных раундов. Дальше запрашиваются только новые записи, объединение — по ID. Одинаковые коэффициенты разных раундов сохраняются. Время отображается по Киеву. Оценочные метки не используются для расчёта времени окна.

Обычные цели рассчитываются правилами De. Крупные цели Ce проверяются независимо от уже закреплённого обычного окна. Ветка 120× требует минимум трёх результатов 50×+ и шести 20×+ среди последних 80: начало через 3 минуты, длительность 6 минут. Опубликованные цель и время сохраняются до завершения окна. Баллы правил не являются проверенной вероятностью попадания.

## Проверки

`node --test tests/*.test.mjs`

Содержатся тесты серверного чтения, пагинации, нормализации, правила 120×, фиксации окон и обновления приложения. Это технические тесты, не доказательство точности прогнозов.

## Серверный исходник

`worker/index.js` — самостоятельный Cloudflare Worker. Для своего развёртывания задайте SUPABASE_URL и SUPABASE_ANON_KEY через секреты окружения. `.env.example` содержит только названия параметров. Используйте ключ с ролью anon/publishable и корректные политики чтения; служебный ключ здесь не требуется. Пример конфигурации — `wrangler.jsonc`.

Сервер отдаёт только нашу разрешённую таблицу истории, ограничивает размер запроса и не принимает произвольные адреса источников. Публичный read-only API разрешает чтение отдельному HTML через CORS. Учётные данные и исходные сессии в репозиторий не включены.

Эта версия находится в отдельном каталоге и отдельной ветке. Основные страницы проекта не изменяются.
