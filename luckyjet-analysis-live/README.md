# LuckyJet Analysis Live

Отдельная сборка пользовательского архива `luckyjet-analysis.zip`. Существующие страницы не изменены.

## Что подключено

- Наша Supabase: публичное чтение `luckyjet_classic_history`, состояние `luckyjet_cloud_status`. Игровых session-id, паролей и сервисных ключей здесь нет.
- Лента последних пяти раундов; весь доступный архив загружается страницами по 1000 записей и сохраняется в IndexedDB. Новые раунды проверяются каждые 5 секунд, пока страница открыта.
- Дедупликация по ID: одинаковые коэффициенты разных раундов сохраняются, 1.00 не подменяется на 1.01. Конфликтующие записи исключаются.
- Дата и время записи до секунды в Europe/Kyiv. Это время записи источником, не подтверждение точного момента ставки.
- Локальный журнал показывает цель, закреплённое окно, фактический коэффициент, время и ID подтвердившего раунда. Неполная проверка повторяется после поступления данных. Промах учитывается только при непрерывном покрытии; разрывы feed_order трактуются консервативно как недостаток данных.

## Алгоритмы и происхождение

`extracted/basic-forecast.mjs`, `signal-validation.mjs`, `trajectory.mjs`, `vortex-local.mjs`, `assets/original.css` перенесены из предоставленного пользователем архива. Анимация WebGL включает паука; при недоступном WebGL используется CSS-круг. Можно отключить анимацию.

Архив содержит базовую эвристику, но не реализацию серверного VIP-алгоритма. Мы не вызываем его закрытые адреса. Базовый алгоритм использует последние 2000 известных раундов. Его баллы — оценки правил, а не измеренная вероятность выигрыша.

Карточки 40× / 200× / 500× используют нашу отдельную модель: последние 10000 достоверных раундов, минимум три события, медианный интервал между событиями. Следующее ориентировочное время = время последнего события + медиана. Окно длится три минуты; прошедший ориентир не переносится вперёд произвольно. Расчёты фиксируются до проверки, без пересчёта задним числом. Случайные будущие краши этим не определяются; преимущество над случайным выбором не доказано.

База продолжает собирать коэффициенты в облаке. Новые локальные расчёты и их журнал работают только при открытой странице; журнал привязан к текущему браузеру. При устаревшем источнике новые окна не создаются.

## Проверка

`npm ci --ignore-scripts` и `npm test`: исходные проверки архива + тесты данных, окон, повторной проверки и DOM. Проверка DOM не заменяет визуальную проверку в браузере.

Публикация: каталог `luckyjet-analysis-live` в GitHub Pages. Все пути относительные. Для локального просмотра нужен HTTP-сервер, например `python -m http.server 8080` из этого каталога.
