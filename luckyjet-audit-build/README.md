# GOD PREDITOR · Archive Edition

Отдельная рабочая сборка предоставленного `historique-public-audit-20261031.zip`.

## Перенесено из ZIP

- `PredictionPanel-BwmEfDz4.js`: математические функции базового прогноза и выбора цели, включая крупные возможности.
- `analysis-data-BaiXRb_2.js`: нормализация, удаление повторяющихся ID, проверка свежести.
- `premium._game-yGdvscKg.js`: траектория паука и проверка попаданий в трёхминутные окна.
- `vortex-scene-BPgrQS3F.js`: WebGL-анимация круга и паука; импорты привязаны к самостоятельным модулям.

Публичные React-сборки не являются полным исходным проектом: в архиве нет части импортов, стилей и серверных функций. Поэтому интерфейс собран отдельно на русском языке. Исходный ZIP сохранён без изменений, SHA-256 перечислены в `source-provenance.json`.

## Наше подключение

Используется существующий публичный источник нашей Supabase: `luckyjet_classic_history` и `luckyjet_cloud_status`. Лента обновляется раз в 5 секунд при открытой странице. Все доступные записи загружаются постранично, кешируются в IndexedDB и доступны в боковой истории. Одинаковые коэффициенты разных раундов сохраняются; верхнего ограничения коэффициента для архива нет. Показывается время записи источником по Киеву до секунды.

Базовый прогноз использует последние 2000 достоверных раундов. Новые расчёты при несвежих данных приостанавливаются. Окна и цели фиксируются до результата. Подтверждение попадания содержит реальный коэффициент и ID раунда; промах требует полного покрытия. Неполная проверка остаётся неизвестной и повторяется после поступления данных. Журнал локален для браузера. Сборщик Supabase работает отдельно в облаке.

## Чего нет

Формулы серверного VIP-времени и серверной ИИ-модели в ZIP отсутствуют. Страница не вызывает чужие закрытые функции, не выполняет регистрацию и не подделывает подписку. Карточки 40× / 200× / 500× показывают только частоты и интервалы исторических событий, без подмены отсутствующих прогнозов собственной формулой. Базовые правила, включая возможную цель 120×, сохранены.

Баллы правил не являются измеренной вероятностью успеха. Точность прогнозов и преимущество над случайным выбором не подтверждены.

## Запуск и тесты

Статическая страница: откройте через HTTP-сервер или GitHub Pages. `npm ci --ignore-scripts`, затем `npm test`. Проверки математики и DOM не заменяют визуальную проверку WebGL на устройстве.
