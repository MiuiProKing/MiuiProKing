Изолированная версия в `god-preditor-v15/`. Оригинальная папка `luckyjet-time-echo/` не изменяется.

## Запуск
Открыть `index.html` на HTTPS static host. Для GitHub Pages нужен включённый Pages (Settings → Pages → Deploy from a branch → main → /(root)). Код HTML/CSS/JS лежит в одной папке. Можно открыть напрямую через совместимый сервис HTML-preview, поддерживающий относительные ES-модули.

## Источник
Supabase `stzrirukuxcyalrsstxx`, таблица `public.luckyjet_rounds`, только `completed=true`, `estimated=false`. Нужны `id,source_seq,coefficient,round_timestamp`. Используется **только publishable key**, доступный браузеру при действующей RLS-политике на SELECT; никакого `service_role`, Telegram-токенов или прав записи. Данные загружаются в памяти по 1000 строк с фиксацией верхнего `source_seq` для фонового сканирования; свежая верхушка опрашивается каждые 15 секунд. Отключения, RLS и отсутствие новых данных показываются явно.

## V15 аналитика
- Target V6: среднее 3 последних × 1.10, максимум 2.40× (это **эвристика**, не фактический предсказанный X).
- Bayesian base: Beta(0.5,0.5) сглаживание частоты пороговых событий, преобразование в P(≥X за следующие N раундов).
- Empirical conditional survival: среди прошлых межсобытийных интервалов длиннее текущей задержки, доля завершившихся в горизонте N (Beta(1,1) сглаживание). Если в рисковом наборе меньше 20 интервалов — выводится «—».
- Weibull survival/hazard: форма оценена по коэффициенту вариации межсобытийных интервалов; вероятность условная на текущую задержку.
- Bootstrap 95%: блочный bootstrap из последних ≤5000 наблюдений; не считать это доказательством точного прогноза.
- Медиана/MAD интервалов, EMA20/EMA50, кластеры ≥20×/50×/100×, исторические минутные и секундные окна в Europe/Kyiv.
- Walk-forward backtest: хронологические 70% train / 30% test, сглаженная модель по минутам, Brier score в сравнении с постоянной базовой частотой.
- Контрольный прогноз в браузере: сохраняет X и горизонт N; HIT/LOSE фиксируются по следующим подтверждённым раундам. **Не является результатом реальной ставки**.

## Ограничения
Вероятности калибруются только на истории; в случайной игре частотные и временные «паттерны» могут не давать преимущества над baseline. Прогноз точной секунды и гарантированный коэффициент получить из этого источника нельзя. Эта версия только читает данные, не делает ставок, не записывает сигналы в Supabase и не отправляет сообщения в Telegram. Для воспроизведения VIP серверной AI-модели из архивов недостаёт серверного кода.
