Session ID Reader

Скрипт для Safari на iPhone: показывает session-id только из адресов твоей открытой игры и её iframe, если такой параметр там действительно присутствует.

iPhone · Safari · Userscripts

Установить скрипт

Оригинальный код сохранён в отдельном файле session-id-iphone.user.js без изменения логики.

Открыть файл для установки Посмотреть код на GitHub
Как пользоваться

Три шага

  1. Установи совместимое расширение Userscripts для Safari и добавь в него файл по ссылке выше. Разреши работу только на нужных игровых доменах.
  2. В Safari открой собственную активную игровую сессию на one-vv1935.com или 1play.gamedev-tech.cc.
  3. На странице игры нажми плавающую кнопку Session ID, затем Найти.
Важно: эта страница GitHub Pages не умеет читать session-id с другого сайта. Сам скрипт должен запускаться расширением непосредственно на странице игры. Если ID передаётся только в скрытых заголовках, он может не обнаружиться.
Приватность

Данные остаются на устройстве

В загруженном скрипте нет сетевой отправки результатов. Он показывает найденный ID локально, а копирование выполняет только после твоего нажатия.

Не публикуй действующий session-id в репозитории, скриншотах или переписках. Никогда не вводи его в эту страницу: здесь нет поля для ввода и нет проверки действительности токена.
